## Update to work with ponyc 0.70.0

Updated for compatibility with ponyc 0.70.0.

## Rename `HtmlTemplate` to `HTMLTemplate`

`HtmlTemplate` has been renamed to `HTMLTemplate` to follow Pony naming conventions for acronyms. Update any references in your code:

```pony
// Before
let tmpl = HtmlTemplate.parse("...")?

// After
let tmpl = HTMLTemplate.parse("...")?
```
